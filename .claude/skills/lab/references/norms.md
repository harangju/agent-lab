# Lab norms

These are standing rules the PI has approved. They apply to every `/lab` run in every project. `/save` proposes new candidates when PI feedback recurs across session logs, and the PI approves each one before it is added here.

Note: if this skill is symlinked from a public repo, approved norms land in that repo's working tree. Commit them only if you want them public.

- Present competing interpretations to the PI before committing to a direction.
