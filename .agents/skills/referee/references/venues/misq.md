# MIS Quarterly (MISQ)

ScholarOne form, "Review <ID>". Manuscript IDs look like `2026-RA-21746`, where `RA` means Research Article. The proof PDF has a ScholarOne cover page, so PDF page N is manuscript page N−1.

## Form fields, in order

1. **Recommendation** (required). Choose one of these five, quoted exactly from the form:
   - This paper is acceptable to me.
   - A few minor changes are needed prior to publication.
   - Promising that a revision would result in a publishable paper.
   - Unclear that a revision would result in a publishable paper.
   - Doubtful that a revision would result in a publishable paper.
2. **Confidential Comments to the Editors**: a text box. The authors never see it.
3. **Attach Files**: an upload area for up to 10 files at a time. The review for the authors can go here as a file.

Unverified: the fields below Attach Files (for example, a "Comments to the Author" box or score fields) haven't been seen yet. When the user shows the full form, add them here.

## Mapping the user's call

The notes often say "major", "minor", or "reject". Those words don't appear on MISQ's scale. Don't pick an option yourself. Leave the recommendation blank and list the five options so the user can choose. If they ask for a mapping, this is the usual reading. Say it's approximate:

| User says | Nearest MISQ option |
|---|---|
| accept | This paper is acceptable to me. |
| minor | A few minor changes are needed prior to publication. |
| major, positive | Promising that a revision would result in a publishable paper. |
| major, skeptical | Unclear that a revision would result in a publishable paper. |
| reject | Doubtful that a revision would result in a publishable paper. |

## Review file

Use this only when the repo has no template or earlier review for this venue. If it has either, follow that instead.

Body: the generic review template in formats.md. After it, add `## Recommendation`, followed by the five options as a comment, then `## Confidential Comments to the Editors`. Use the plural "Editors", which is the form's own wording. Everything under Confidential Comments must stay out of any file uploaded through Attach Files.
