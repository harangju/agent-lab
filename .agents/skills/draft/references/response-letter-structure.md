# Response Letter Structure

Use this for journal R&R response letters. Strategy (concede/redirect, movable vs immovable, score engineering) lives in the project's revision craft docs when present. This file is the reusable layout and reply recipe.

## Letter Layout

1. Opening gratitude + overview.
   - Thank the editor and reviewers briefly.
   - One short paragraph: decision context, how you revised, and the paper's scoped claim after revision.

2. Summary of major changes (optional but useful).
   - Bullets mapping big asks to manuscript deltas.
   - Helps the AE skim before the point-by-point.

3. Point-by-point replies.
   - Group by editor, then R1, R2, ... in the order of the decision letter.
   - Keep reviewer quotations intact when the project uses `\reviewer` (or equivalent); never edit `reviews.md`.

4. Closing.
   - Short offer to do further clarifying edits.
   - No new scientific fights in the last paragraph.

## Per-Point Reply Recipe

For each reviewer point:

1. Restate or quote the ask (so the reply stands alone).
2. Answer in the letter itself: what you conclude and what you did.
3. Name the manuscript change (analysis, table, paragraph, figure).
4. Point to where it lives (section, page, figure, `\revision` block).
5. If you concede, say so plainly; keep the finding; redirect into what the evidence supports.
6. Stop. Do not open unasked fronts.

Shape to aim for: *Reviewer said X → we did Y → see §Z / Fig N.*

## Tone

- Grateful, precise, short.
- Make the reviewer the co-author of the fix ("Following R2, we now...").
- No sarcasm, no "the reviewer misunderstood," no multi-page philosophy.
- Overwhelm with concrete work done, not rhetoric.

## Editing Checks

- Every major point maps to a visible manuscript delta (or an explicit, scoped concession).
- `\revision` (or quoted manuscript text) matches the revised PDF.
- Abstract, intro punchline, discussion, and captions all reflect the same scoped claim.
- Do not discuss issues the reviewers did not raise.
- Pure argument with no change rarely moves a score; prefer a small honest edit over a clever rebuttal.
