# PI Local Profile Template

Save your personal copy **outside** any public repository — default location:

```text
~/.config/agent-lab/irb-profile.md
```

(Or keep a gitignored `irb-profile.md` inside a private project repo. Never commit real contact info, grant numbers, or CITI filenames to a public repo.)
